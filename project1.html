Building a Website for Selena's Salvadorian Restaurant

Why This Project Matters

I am using what I have learned in APCV 310: Introduction to Computing to build a website for a family friend's restaurant, Selena's Salvadorian Restaurant. The restaurant had no online presence, and this project is helping them showcase their culture, food, and passion for Salvadorian cuisine to the broader community.

What I Learned and Applied

In this class, I learned how to build basic HTML pages, apply CSS styles, and structure a site with good navigation and accessibility. I used:

  • HTML elements like headers, paragraphs, lists, images, and links
  • CSS styling for fonts, colors, and page layout
  • Best practices for organizing files and linking pages
